## Featured work

### 🏆 [SignalAF / SigRank](https://signalaf.com) — measure AI operators

A public leaderboard for people operating AI, with operator profiles, peer comparisons, and token-usage metrics. Evaluate observable operating patterns rather than ranking the underlying AI models.

**[Leaderboard](https://signalaf.com)** · [Compare operators](https://signalaf.com/compare) · [Web source](https://github.com/SunrisesIllNeverSee/sigrank-app) · [CLI / MCP](https://github.com/SunrisesIllNeverSee/sigrank-mcp)

```bash
npx sigrank
```

The CLI reads supported local usage metadata; public submission is optional. The ranked telemetry uses token counts rather than prompt or response text. [Methodology](https://signalaf.com/methodology) · [Privacy details](https://github.com/SunrisesIllNeverSee/sigrank-mcp#privacy)

### 🗂️ [AQUA](https://aquaidp.xyz) — stop rewriting applications

Archive applications, organize their questions, and reuse answers you have already approved. Assemble drafts for accelerators, grants, jobs, fellowships, and education from a local-first answer bank.

**[Explore AQUA](https://aquaidp.xyz)** · [Application Hub source](https://github.com/SunrisesIllNeverSee/application-hub) · [Claude plugin](https://github.com/SunrisesIllNeverSee/aqua-idp-claude)

### 🤖 [Signomy](https://signomy.xyz) — govern agent collaboration

An agent marketplace and runtime for teams, missions, and accountable execution. Agents operate through role controls, governance checks, and provenance records.

**[Explore Signomy](https://signomy.xyz)** · [Source / CIVITAE runtime](https://github.com/SunrisesIllNeverSee/agent-universe)

## Research behind the products

- **[Commitment Theory](https://github.com/SunrisesIllNeverSee/Commitment_Theory)** studies whether obligations, permissions, and prohibitions are preserved when language or instructions are transformed. [Published conservation paper](https://doi.org/10.5281/zenodo.20029607).
- **[MO§ES™](https://github.com/SunrisesIllNeverSee/MOS2ES)** develops execution-time governance, constraints, and evidence of what a system actually did.
- **[TTEOP](https://github.com/SunrisesIllNeverSee/tteop-spec)** is an experimental, vendor-neutral specification for interoperable AI-operator token telemetry.

The repositories contain the protocols, evidence, implementation details, tests, and limitations.
